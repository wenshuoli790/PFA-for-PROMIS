# PFA-for-PROMIS
This is the repository for codes and supplemental materials for the manuscript "From sentence embeddings to item properties: An application of pseudo-factor analysis with patient-reported outcome measures"
The PROMIS dataset used for data analysis can be accessed at Cella, D. (2022). PROMIS 1 Wave 1. Harvard Dataverse. https://doi.org/10.7910/DVN/0NGAKG
